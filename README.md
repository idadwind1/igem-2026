# iGEM 2026 Wiki

Wiki for the iGEM 2026 project: **Yeast Modification for Decomposing Garden Waste**.

Built with [Astro](https://astro.build), [Tailwind CSS v4](https://tailwindcss.com), and [Lenis](https://lenis.darkroom.engineering).

## Getting Started

```bash
pnpm install
pnpm dev
```

## Commands

| Command        | Action                               |
| -------------- | ------------------------------------ |
| `pnpm dev`     | Start dev server at `localhost:4321` |
| `pnpm build`   | Build for production to `./dist/`    |
| `pnpm preview` | Preview production build locally     |

## Requirements

- Node.js >= 22.12.0
- pnpm
